SunTrack ☀️

SunTrack is a beginner-friendly Python project that calculates the approximate solar panel angle based on the sun’s position.

The project helps demonstrate how the position of the sun changes during the day and how this can affect the orientation of a solar panel.

🌱 Purpose

Solar panels receive the most sunlight when they are positioned at a suitable angle toward the sun.

SunTrack was created to explore this basic concept using Python and simple calculations.

The project can be used as a small simulation/calculation tool for understanding:
	•	Solar panel orientation
	•	Sun position
	•	Angle calculations
	•	Basic solar energy concepts
	•	Python programming and calculations

🛠️ Technologies Used
	•	Python
	•	Mathematical calculations
	•	Basic user input and output
